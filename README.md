# Telegram-бот с OpenAI (ChatGPT)

Простой Telegram-бот на Python 3.11+, который:
- отвечает на сообщения через OpenAI,
- хранит контекст последних сообщений пользователя (до 10 пар `user/assistant`),
- поддерживает команды `/start` и `/reset`,
- ограничивает частоту запросов (1 запрос в 2 секунды на пользователя),
- логирует ошибки в консоль.

## 1) Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
```

## 2) Настройка переменных окружения

Создайте `.env` на основе шаблона:

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения.

Пример:

```env
TELEGRAM_BOT_TOKEN=1234567890:your_telegram_bot_token
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4.1-mini
```

> В коде нет захардкоженных ключей — все секреты только через переменные окружения.

## 3) Запуск бота локально

```bash
python main.py
```

После запуска отправьте боту `/start` в Telegram.

## Команды бота

- `/start` — приветствие и инструкция.
- `/reset` — очистка истории диалога пользователя.

## Примечания

- Используется **OpenAI Responses API** через официальный SDK `openai`.
- История хранится в памяти процесса (in-memory), поэтому при перезапуске бота очищается.
